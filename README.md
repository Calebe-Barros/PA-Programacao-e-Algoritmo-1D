## 📌 Sobre o Repositório

Este repositório foi criado para armazenar atividades, exercícios, projetos e estudos desenvolvidos durante as aulas de **Programação e Algoritmo**.

Aqui serão reunidos códigos e projetos desenvolvidos com o objetivo de praticar lógica de programação, algoritmos, estruturas de decisão, repetição, variáveis e outros conceitos fundamentais da programação.
